One-time setup — connect this page to your Firebase project.

  1. Copy firebase-config.example.js to firebase-config.js.
  2. Paste your project's web config from the Firebase console into it.
  3. Commit and redeploy. Full steps are in the README.

The web config is safe to publish — access to the data itself is controlled by Firebase sign-in and security rules, not by hiding the config.
